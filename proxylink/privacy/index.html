Privacy Policy

Effective date: July 4, 2026. ProxyLink is a native proxy connection tool that forwards device traffic to the proxy server you configure.

Provider: ProxyLink Support: gxtuna@gmail.com

1. Data We Collect

ProxyLink does not collect, upload, sell, or share your personal information, proxy profiles, request contents, visited domains, IP address lists, or network traffic. The app currently does not include advertising SDKs, third-party analytics SDKs, or an account system.

2. Data Stored On Your Device

ProxyLink stores the following information locally on your device to provide the proxy connection feature:

Proxy profiles Profile name, proxy host or IP address, port, protocol type, and the selected profile.
VPN configuration The iOS-managed VPN configuration required to start the Packet Tunnel and connect to your configured proxy server.
Privacy notice state Whether you have accepted the privacy and network notice shown before the first connection.

3. How Network Traffic Is Handled

When you connect, ProxyLink forwards traffic covered by the iOS VPN route to the proxy server you configured. ProxyLink does not operate proxy servers and cannot control the proxy server or proxy service provider you choose. Your proxy server or provider may process your network traffic under its own terms and privacy practices.

4. Permissions

  • VPN configuration permission is used to create and start the iOS Packet Tunnel.
  • Local Network permission is used when your proxy server is on your local network.
  • WLAN and Cellular Data access is used so the app can access the network and check proxy reachability.

5. Data Deletion

You can clear saved proxy profiles from the app settings page, or uninstall the app to remove locally stored app data. The iOS VPN configuration can also be managed or removed in system Settings.

6. Children’s Privacy

ProxyLink is not directed to children and does not knowingly collect personal information from children. If you believe a child has provided personal information to us, contact us at the support email below.

7. Changes and Contact

If this policy changes materially, we will update this page. For privacy or support questions, contact gxtuna@gmail.com.
