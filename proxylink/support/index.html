Troubleshooting

  • Make sure the proxy server is running and the IP address, IPv6 address, or port is correct.
  • If the proxy service runs on a Mac or another local network device, make sure your iPhone is on the same network.
  • If you previously denied Local Network, WLAN, or Cellular Data permission, enable them for ProxyLink in system Settings.
  • When using Proxyman or Clash Verge TUN, make sure the desktop proxy listener allows access from LAN devices.
  • After switching networks, disconnect and reconnect ProxyLink.

Important Note

ProxyLink does not provide proxy servers. If your proxy server or network environment is unavailable, the app cannot replace the server or complete the connection on its behalf.
